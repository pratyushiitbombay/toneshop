# Toneshop

Turn a link or a song file into a ringtone, alarm or remix in a few clicks: pick the part, add a vibe, export for iPhone
or Android. A free Mac app for Macs with Apple silicon (macOS 13 Ventura or later). No account, no uploads.

**Website and download:** https://pratyushiitbombay.github.io/toneshop

Downloads are on the [Releases](https://github.com/pratyushiitbombay/toneshop/releases) page. Toneshop isn't signed with a
paid Apple developer account, so macOS asks you to approve it once: the website explains how.

This repository holds the website only. The demo songs on the page are original tracks made for Toneshop.
